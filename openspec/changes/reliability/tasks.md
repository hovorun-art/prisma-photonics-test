# Tasks

## Plan

1 (contracts, kernel error code, domain interfaces, config, migration) → 2 (job-service: backoff,
attempt-aware reports, idempotency), 4 (job-execution-service) and 5 (job-ui) → 3 (job-service:
recovery pass, which edits the same service files as 2) → 6 (integration: system e2e,
DECISIONS.md, roadmap, full checks). Groups 2, 4 and 5 need only group 1 and own disjoint files, so
they could run in parallel; 3 after 2; 6 last, alone. After group 1 the implementing classes do not
typecheck until their group adds the new members; group 1 verifies with the contracts and kernel
workspaces and the interface files only.
